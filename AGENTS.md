# TugasRapi maintenance

Keep the app static and dependency-free. User text must use textContent, never innerHTML. Save to localStorage before changing in-memory tasks; preserve existing data on validation/write failure. Keep asset links relative for GitHub Pages. Run `node --check app.js` and `node test.cjs` after JavaScript edits. Check real browser CRUD, persistence and mobile layout for UI changes. Document evidence and limitations in migration-notes.md. Commit meaningful increments only; never manufacture history.
