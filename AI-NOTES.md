# Catatan penggunaan AI

Tools: Codex untuk proyek TugasRapi; Kilo Code untuk latihan bug fixing dan prompt CRUD terpisah.

Codex membantu perencanaan UI, implementasi HTML/CSS/JavaScript, CRUD, penyimpanan lokal, filter dan pencarian, validasi, uji regresi, dokumentasi, Git, serta deployment GitHub Pages.

Verifikasi dilakukan melalui `node --check app.js`, `node test.cjs`, dan interaksi browser untuk tambah/edit/hapus, status selesai, filter terlambat, pencarian kosong, reload, serta input HTML. Tampilan desktop dan mobile diperiksa dengan screenshot dan pengukuran overflow. Ini tidak membuktikan dukungan seluruh browser atau aksesibilitas penuh.
